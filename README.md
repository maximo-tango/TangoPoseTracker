# TangoPoseTracker

GitHub Pages에서 바로 사용할 수 있는 정적 웹 앱입니다. 탱고 댄스 영상을 업로드하면 두 명의 인물을 인식하고, 정지 프레임에서 머리와 관절을 수동으로 지정한 뒤 움직임을 추적해 스켈레톤을 따라가도록 구성했습니다.

## 주요 기능

- 영상 업로드
- 영상 뷰어 위에 오버레이 표시
- 두 명의 인물 각각에 대해 포인트 지정
- 머리, 어깨, 팔꿈치, 손, 골반, 무릎, 발 점을 클릭
- 점들을 선으로 연결해 스켈레톤 구성
- MediaPipe 포즈 추적을 통해 이후 프레임 자동 추적

## 사용 방법

1. 저장소를 로컬로 복사합니다.
2. 브라우저에서 `index.html`을 열거나 로컬 서버를 실행합니다.
3. `영상 업로드` 버튼으로 탱고 동영상 파일을 선택합니다.
4. 모바일에서는 영상 위를 좌우로 밀어 프레임을 탐색하고, 두 손가락으로 확대합니다. 확대된 화면은 두 손가락으로 이동합니다.
5. 영상을 일시정지한 뒤 `PNG ↓`를 눌러 현재 프레임을 이미지로 저장합니다.
6. `정지 프레임 점찍기`를 누르고, 각 사람의 머리와 관절 점을 차례대로 클릭합니다.
7. `동작 추적 시작`을 눌러 이후 프레임에서 인식 결과를 따라가게 합니다.
8. `내보내기 속도`에서 `0.25×` 또는 `0.5×`를 고르고 `포즈 포함 영상 저장`을 눌러 포인트 오버레이가 합성된 영상을 다운로드합니다. 브라우저 지원에 따라 MP4 또는 WebM으로 저장됩니다.

## 로컬 실행

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 으로 접속합니다.

## GitHub Pages 배포

1. 저장소를 GitHub에 업로드합니다.
2. GitHub 저장소에서 `Settings` → `Pages`로 이동합니다.
3. `Deploy from a branch`를 선택하고 `main` 브랜치, `/ (root)`를 설정합니다.
4. 배포가 완료되면 Pages 주소를 통해 정적 사이트를 이용할 수 있습니다.

## 참고

이 프로젝트는 서버가 없는 정적 페이지 구조를 사용하므로 GitHub Pages에 그대로 배포할 수 있습니다. 포즈 추적은 브라우저에서 MediaPipe Tasks Vision과 Google 호스팅 Pose Landmarker Lite 모델을 로드해 처리합니다. 모델 파일은 약 5.8MB이며, 최초 추적 실행 시 인터넷 연결이 필요합니다.

## 업데이트 (안정화 + 유튜브 오버레이)

- 수동 지정한 26개 점으로 두 댄서의 ID를 고정하고(추적 시작 시 지정한 프레임으로 이동), One Euro 필터로 떨림을 줄입니다. 신뢰도 낮은 점은 그리지 않습니다.
- 모델을 Pose Landmarker **Full**로 변경, ←/→ 는 1프레임(Shift는 1초) 이동, ◁ ▷ 버튼 추가.
- 좌/우 표기는 **인물 본인 기준**입니다(마주 보면 화면상 반대).
- **유튜브 오버레이:** 추적을 켠 채 영상을 끝까지 재생 → `분석 JSON 저장` → `youtube.html`에서 유튜브 링크 + JSON 불러오기. `youtube.html?v=영상ID&data=data/파일.json` 형태로 저장소에 JSON을 넣어 링크 공유도 가능합니다.
- 유튜브 임베드는 `http(s)`에서만 동작합니다(`file://` 불가). 오버레이를 유지하려면 유튜브 자체 전체화면 대신 페이지의 전체화면 버튼을 쓰세요.

## 업데이트 2 (정밀 모델 + 탱고 분석)

- 툴바에서 추적 모델 선택: 경량(Lite) / 표준(Full) / 정밀(Heavy). 추적 중 바꾸면 모델을 다시 불러옵니다.
- **탱고 분석 카드:** 몸통 기울기(+는 화면 오른쪽), 가슴-골반 각도차, 두 사람 거리(몸통 길이 단위), 발 궤적 표시. 유튜브 페이지에서도 분석 JSON으로 동일하게 표시됩니다.
- 모든 수치는 2D 영상 기준 근사값이라 카메라 각도에 따라 달라집니다.
